# Security Policy

## Reporting Security Issues

We take the security of Doom Term seriously. If you discover a vulnerability in Doom Term, please report it promptly.

### Scope
- Command Risk Interceptor (`src/core/securityAnalyzer.ts`)
- PTY Child Process Isolation & Sandbox Handlers (`backend/src/pty/session.rs`)
- WebSocket Authentication Gateway (`backend/src/main.rs`)

### Reporting Process
Please email security concerns to the maintainers or open a private security advisory on GitHub.

Please do **not** disclose vulnerabilities in public GitHub issues until a patch has been released.
