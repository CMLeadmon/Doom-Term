# Support

Doom Term is a community-maintained desktop terminal. There is no paid support contract or guaranteed
response time. Warp's support channels do not support this fork.

- Start with [installation](docs/doom-term/getting-started.md) and [the documentation index](docs/doom-term/README.md).
- For a reproducible defect, use [the bug form](https://github.com/CMLeadmon/Doom-Term/issues/new?template=01_bug_report.yml).
- For SSH or remote status problems, use [the SSH form](https://github.com/CMLeadmon/Doom-Term/issues/new?template=03_ssh_tmux.yml)
  and [the status setup guide](docs/doom-term/remote-agent-status.md).
- For a feature, describe the workflow in [the feature form](https://github.com/CMLeadmon/Doom-Term/issues/new?template=02_feature_request.yml).
- For usage questions, [open an issue](https://github.com/CMLeadmon/Doom-Term/issues/new) with a concise description.
- For vulnerabilities, use the private channel in [SECURITY.md](SECURITY.md).

Include your release or commit, OS, architecture, shell, and what you already tried. Remove passwords,
tokens, private connection details, and personal session data from public reports.

For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Contact options, if published,
are on [the maintainer's GitHub profile](https://github.com/CMLeadmon). If no private contact method is
available, request one in an issue without publishing the incident or identifying details.
