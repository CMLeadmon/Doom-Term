## Themes

Theme packs are optional release assets. Extract the entire pack into the documented themes folder;
copying only the YAML file leaves the animation behind. Verified theme installation paths and known
limits are listed in each guide.

- [Redsky](redsky-theme.md): storm, skyline, and plate color
- [Blue Highway and Canopy](blue-highway-and-canopy-themes.md): generated landscape animations
- [Replay](replay-theme.md): recorded shareware gameplay
- [BFR](bfr-theme.md): recorded gameplay with separate third-party asset rights
