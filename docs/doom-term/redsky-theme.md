# Redsky theme pack

An optional animated theme for Doom Term: a black sun behind drifting storm clouds, three skyline layers panning at
different speeds, and two lightning strikes, with its own palette. It is a **theme pack** (a YAML file, a GIF and a
short install note), not part of the application, so a Doom Term that never installs it is unchanged.

Design and decisions: [`docs/superpowers/specs/2026-10-01-redsky-theme-design.md`](../superpowers/specs/2026-10-01-redsky-theme-design.md).

## Install

Download `doomterm-redsky-theme.zip` from the release and check it against that release's `SHA256SUMS.txt`. Extract it
into Doom Term's themes folder so a `redsky` folder ends up inside it:

| Platform | Themes folder |
| --- | --- |
| Linux | `~/.local/share/doomterm/themes/` |
| macOS, Windows | not yet verified |

Doom Term watches that folder, so the theme appears without a restart: Settings, Appearance, Themes, **Redsky**.

The theme finds its animation by the path `redsky/redsky.gif` **under the themes folder**, not next to the YAML. Moving
only `redsky.yaml` elsewhere loads the theme with a flat background and no animation.

To remove it, delete the `redsky` folder.

## What it looks like

The animation is drawn at image opacity **10**, so it stays a faint ghost behind the text. Edit `opacity` in
`redsky/redsky.yaml` to change that; 100 shows it at full strength, at the cost of readability behind text.

The YAML also carries a `plate_stone` key that recolours the status plate's stone (a dull wine-maroon; the bevels, wells
and labels stay as they are). Support for the key is in `main` and **not yet in a release**: builds without it,
including v1.1.5, ignore the key and keep the grey plate. A theme whose `plate_stone` is not a valid hex colour still
loads; the plate just stays grey.

## Cost

Measured on v1.1.5 in the headless lab: about **58 MiB** more resident memory while the theme is active (the renderer
keeps every frame decoded: 480 × 300 × 4 bytes × 100 frames). The GIF is 1.9 MB. Frame cadence and GPU cost on a real
display have not been measured.

## Regenerate and package

The animation is generated by `crates/doomterm_backdrop`, a pure deterministic generator, and committed as
`themes/redsky/redsky.gif`.

```sh
CARGO_TARGET_DIR=$HOME/.cache/doomterm/host-target \
  cargo run --release -p doomterm_backdrop --example bake_redsky -- themes/redsky/redsky.gif
cargo test -p doomterm_backdrop            # includes a check that the committed GIF matches the generator
python3 script/doomterm/package_redsky_theme.py   # writes target/redsky/doomterm-redsky-theme.zip, prints its SHA-256
```

The zip is reproducible: building it twice gives identical bytes.
